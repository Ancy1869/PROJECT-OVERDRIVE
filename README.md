# PROJECT-OVERDRIVE

Unity 6 / URP multiplayer hero-shooter project.

## Unity project
Open this repository folder with Unity Hub after cloning it. The Unity project root contains:
- `Assets/`
- `Packages/`
- `ProjectSettings/`

## Team workflow
- Commit Unity source assets and their `.meta` files.
- Do not commit generated folders such as `Library/`, `Temp/`, or build output.
- Coordinate before changing shared scenes or project settings.
